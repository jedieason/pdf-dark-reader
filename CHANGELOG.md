# Changelog

## 1.0.0 — 2026-09-14

- First public release of PDF Dark Reader for Chrome.
- Added Light, Dark, and System appearance modes with live updates.
- Added PDF-aware remapping of simple text/vector colors while preserving embedded raster images.
- Added full-page inversion as a manual fallback for scans.
- Packaged a modified, pinned PDF.js Chromium viewer with a burgundy-accented popup.
- Added service-worker import validation and removed upstream extension telemetry.
