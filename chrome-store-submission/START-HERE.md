# Submission pack

1. Upload **pdf-dark-reader-1.0.0.zip** in the Chrome Web Store Developer Dashboard.
2. Copy the listing, review, and disclosure text from **CHROMEWEBSTORE.md**.
3. Upload the icon, four screenshots, and promotional images in **store-assets/**.
4. Publish **privacy-policy.md** or **privacy-policy.html** at a public URL. Verify the policy's support link works and enter that public URL in the dashboard. Repository-based URLs in the listing file are candidates, not verified live pages.
5. Complete account-specific contact/verification/trader-status details, choose distribution, and perform the reviewer smoke-test steps before submitting for review.

The ZIP packages the committed, ready-to-load extension rather than downloading a new upstream build. It includes the same 16/32/48/128px mascot icons as the repository extension and attribution notices. The separate store icon has listing padding. All JavaScript remains identical to the repository build. Source assets and a reproducible packaging script are included. See VALIDATION.md for checks and limits.

Nothing has been published or submitted. The remaining external requirement is a publicly accessible privacy-policy/contact location plus your developer-dashboard account details.
