# Code of conduct

This project welcomes people with different backgrounds and levels of experience. In issues, pull requests, reviews, and other project spaces, please:

- Be respectful and discuss ideas and code without personal attacks.
- Assume good intent, ask clarifying questions, and give actionable feedback.
- Make space for newcomers and respect different accessibility needs.
- Do not harass, discriminate, threaten, publish private information, or spam.

Maintainers may edit or remove comments, close threads, or restrict participation when these standards are not met. If you need to report a conduct concern privately, contact the repository owner through the contact method on their GitHub profile. If none is listed, open an issue asking for a private contact without including sensitive details.
