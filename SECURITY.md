# Security policy

The current `1.x` release line receives security fixes as the project is maintained. Older releases may not receive backports; please update to the latest release when a fix is published.

**Do not disclose a suspected vulnerability in a public issue.** Use [GitHub's private vulnerability report form](https://github.com/jedieason/pdf-dark-reader/security/advisories/new) and include the affected version, a concise impact description, and steps to reproduce. This repository enables private vulnerability reporting so the maintainer can coordinate a fix before disclosure.

For ordinary bugs without a security impact, use the bug-report issue template.
